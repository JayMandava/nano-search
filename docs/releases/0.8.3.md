# Nano Search 0.8.3

Clock-face change notices now dismiss automatically after six foreground seconds,
with accessibility-recommended timing respected. The notice fills the available
width within system insets, and its Dismiss label aligns with the message while
retaining a 48dp minimum touch target. Repeated changes restart the readable
interval; backgrounding and navigation cancel the active timer appropriately.

Model downloads now show the requested choice separately from the installed
fallback. Verification has one owner per shared file through cleanup, preventing
a duplicate verification from reporting a missing staging file after successful
installation. Downloads and retries use separate staging and temporary files;
cancelled or superseded workers cannot install or publish stale results. Shared
Qwen files are deduplicated, verification runs on one background worker, missing
staging directories are recreated, and successful installations clear stale errors.
Model rows retain stable identities and show failures only for their own missing
parts. Existing downloads from the previous version remain supported.

The original fix commits `784bf2e36b7f10ea791403a4d990e381a125a4ab` and
`9be5f2f1a23110673accd9c0f8f751855bfdaa27` retain their original metadata and
history. Approved RM artwork is unchanged.

Validation covers 186 JVM tests per debug/release variant: zero failures/errors,
one deliberate opt-in PNG-export skip per variant. Those totals include eight
Compose UI tests running under Robolectric/API 35/native graphics and eight tiny-file
download lifecycle tests with shadowed DownloadManager. Tests cover rapid repeated
requests across all models, cancellation/retry, stale workers, cleanup reentry,
error isolation, notice alignment, lifecycle and accessibility-adjusted timing.
Explicit debug/release lint, unsigned R8 assembly, instrumentation-source
compilation, 24 release safeguard tests, public asset provenance, signature absence
and native/APK alignment checks are required for this candidate.

No device/emulator instrumentation, real-network model downloads, process-death
recovery, physical TalkBack/OEM-inset checks or phone frame-time profiling was
performed for these fixes. Robolectric results do not establish phone performance.
Private fonts/personal overlays remain excluded. Production signing still requires
the existing certificate, both owner approval gates and independent v2 verification.

Version code: 18. Package: `ai.nanosearch.launcher`.
