# Nano Search 0.8.5

The Carbon face's upper-left pusher uses the approved four-second race-car
pass-by edit from **Monza track side** by **wandererscapes (Freesound)**, published
by **freesound_community** via Pixabay on July 21, 2022. It is not an authenticated
McLaren recording or endorsement. The recording remains under the Pixabay
Content License, separate from the application's Apache-2.0 source license:
https://pixabay.com/sound-effects/film-special-effects-monza-track-side-69992/
https://pixabay.com/service/terms/

The fixed built-in audio is privately provisioned during the protected release
build and packaged only within the app. No stock audio or encoded payload is
published in Git or as a standalone release artifact. Release packaging rejects a
missing, changed or wrong-format input; developer/debug fixtures retain the
original synthetic sound. The source-only provenance manifest records the original
hash, selected segment, gain/fades and exact Ogg hash.

Accepted RM visuals are unchanged. Playback remains explicit-tap only, with one
voice, debounce, media-volume/DND checks, transient audio focus and existing
hide/detach/screen-off/resize cleanup. No new device permissions or phone-side
download/sound-selection step is introduced. The accessibility action no longer
calls the third-party recording original Nano audio.

The existing two owner approval gates, production certificate pin, APK provenance
and independent v2 verification remain mandatory. Public fixture validation must
not be represented as verification of the privately provisioned production asset.

Version code: 20. Package: `ai.nanosearch.launcher`.
