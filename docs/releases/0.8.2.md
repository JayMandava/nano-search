# Nano Search 0.8.2

Carbon clock artwork now has refined straight bridge proportions, mirrored rear
window frames, and a separate lower counter collar. Front bridge screws and the
two reviewed outer purple jewels are removed. Stray engraved strokes beside
twelve are cleared; the remaining jewels, hands, date and counter geometry stay
unchanged. The four approved artwork commits through
`f1c96f85dedc8f1bcb1167afa689d4c3778737c6` retain their original history.

This release also handles microphone permission revocation explicitly, captures
the settings transition theme, and declares telephony optional. Two intentional
launcher manifest checks have documented leaf-scoped lint exclusions:
`ProtectedPermissions` for `BIND_APPWIDGET` and `QueryAllPackagesPermission` for
`QUERY_ALL_PACKAGES`. The declarations and behavior remain unchanged; this is
not Play distribution approval.

Cloud production releases use an owner-approved GitHub environment and the
existing Nano production certificate. Public artifacts contain only the reviewed
public assets and fonts; private fonts and personal overlays are excluded.

Version code: 17. Package: `ai.nanosearch.launcher`. Native renderer and JVM
checks do not establish new phone, launcher-host, OEM or device lifecycle QA.
